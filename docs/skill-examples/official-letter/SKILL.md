# 공문 작성 절차

먼저 사용자가 제공한 근거, 수신자, 발신자, 목적, 기한을 구분한다.
문서에서 확인되지 않는 기관명, 날짜, 문서번호, 법적 근거를 만들지 않는다.
필수 정보가 없으면 확인이 필요한 항목으로 표시한다.

제목은 요청 목적이 드러나게 작성하고, 본문은 배경 → 요청 사항 → 기한 및
연락 방법 순으로 정리한다. 필요할 때만 번호를 매긴다. 기존 양식을 편집하는
경우 표, 문단 스타일, 결재란과 수신·참조란을 임의로 재구성하지 않는다.

작성 후 원문과 대조하여 수치, 날짜, 고유명사, 요청 범위가 달라지지 않았는지
검토한다. 실제로 수행한 변경만 보고하고, 공공기관의 승인을 받은 문서나
법률 검토를 마친 문서라고 주장하지 않는다.

파일 생성·편집은 앱이 제공한 도구만 사용한다. 지원하지 않는 파일 형식을
확장자 변경이나 XML 추측으로 만들어내지 않는다.
