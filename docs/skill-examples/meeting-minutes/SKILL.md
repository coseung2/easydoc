# 회의록 작성 절차

원본 기록을 읽고 회의 일시·참석자와 안건을 식별한다. 기록에 없는 참석자,
발언, 합의 또는 기한을 추정하지 않는다.

안건별로 논의 내용과 확정된 결정을 구분한다. 후속 조치는 할 일, 담당자,
기한, 미정 사항으로 정리한다. 제안이나 검토 중인 내용을 승인된 결정으로
바꾸지 않는다. 민감한 개인정보는 목적상 필요한 범위만 포함한다.

마지막에 원문과 대조하여 누락된 결정이나 담당자가 없는지 검토한다.
사용자가 요약만 요청했다면 채팅에 답하고, 문서 생성이나 수정을 요청한
경우에만 해당 도구를 실행한다.
