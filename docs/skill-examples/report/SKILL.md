# 보고서 작성 절차

요청의 독자와 의사결정 목적을 확인하고, 제공된 자료부터 읽는다. 필요한
최신 사실은 사용 가능한 검색 도구로 확인한다. 사실, 해석, 제안, 미확인
사항을 구분하며 출처가 없는 수치나 인용문을 만들지 않는다.

핵심 결론 → 주요 근거 → 대안과 제약 → 후속 조치 순으로 구성한다.
표는 실제 비교가 필요한 경우에만 사용하고, 원문에 없는 항목은 빈칸 또는
확인 필요로 표시한다. 분량은 요청 목적에 맞추고 반복을 줄인다.

완성 후 수치와 단위를 원자료와 대조한다. 시트 계산은 앱의 계산·집계
도구를 사용하고 계산 결과를 다시 읽는다. PDF나 슬라이드에서는 내용을
추가할 공간과 기존 배치를 먼저 확인한다. 요청하지 않은 문서 수정은 하지
않으며, 저장·생성이 성공한 경우에만 완료했다고 말한다.
